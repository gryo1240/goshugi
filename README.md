# ご祝儀・香典 早見表

結婚式のご祝儀・お葬式の香典の金額相場と基本マナーが、選ぶだけでわかる無料のWebアプリ(PWA)。

**アプリ本体: https://gryo1240.github.io/goshugi/**

- **お祝い5種**: 結婚式(出席/欠席)・出産祝い・入園入学祝い・新築引っ越し祝い。「相手との関係 × 自分の年代」を選ぶと相場と、袋・水引・表書き・お札・袱紗のマナーを表示
- **香典**: 「亡くなった方との関係 × 年代」で相場を表示。**宗教(仏式/浄土真宗/神式/キリスト教/わからない)を選ぶと表書きが切り替わる**(浄土真宗は御仏前、神式は御玉串料など)
- **マナー知識6本**: 4と9を避ける金額ルール・新札と旧札・袱紗の色・中袋の旧字体(金参萬円)の書き方・薄墨・当日の渡し方
- **完全ステートレス&リライト不要の設計**: 何も入力・保存せず、冠婚葬祭の慣習という数十年安定した情報だけで構成。一度公開したら更新不要
- 外部送信なし・登録不要。一度開けばオフラインでも使える(急な訃報で電波の悪い斎場でも見られる)

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(HTML/CSS/JSすべて1ファイル。相場データ`IWAI_EVENTS`/`KOUDEN_REL`を内蔵) |
| `manifest.webmanifest` / `sw.js` | PWA化(インストール・オフライン対応) |
| `icon-*.png` / `apple-touch-icon.png` | アプリアイコン(金茶に熨斗袋) |
| `docs/screenshot-*.png` | 紹介用スクリーンショット |

`main` ブランチに push すると GitHub Pages に自動デプロイされます。

ブログ等での紹介記事を書く場合は [HANDOVER.md](HANDOVER.md) を参照してください。
